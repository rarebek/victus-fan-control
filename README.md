# Victus Fan Control

Fan control CLI and GTK app for HP Victus laptops using Linux `hp` hwmon.

## Install

```bash
yay -S victus-fan-control-git
# or
paru -S victus-fan-control-git
```

## Run

```bash
fanctl capabilities
fanctl status
fanctl-gui
```

Manual install:

```bash
./install.sh
```
